# Housing Agency site

This repository contains a Next.js website and navigation prototype for The
Housing Agency of Ireland. It explores a clear public-facing structure for
housing information, organisational content, publications, and related
services.

The project is a prototype/site implementation rather than an official source
of policy. Content and links should be checked against the Housing Agency’s
current public information before publication.

## Local development

```sh
npm ci
npm run dev
```

Use `npm run build` to verify a production build. The current deployment is
[ha-site-ebon.vercel.app](https://ha-site-ebon.vercel.app).
